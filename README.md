# HANG-Compiler (hcc)

这是一个基于 **Flex** & **Bison** 开发的类 C 语言（名为 HANG 语言）的自底向上编译器。本项目实现了从高级语言源码到 **x86 汇编代码**的完整编译流程，并支持通过自动化脚本生成可执行二进制文件。

## 🚀 核心特性

- **前端解析**：基于 Flex 和 Bison 构建 LALR 语法分析器，支持嵌套作用域、While 循环、If-Else 分支等。
- **抽象语法树 (AST)**：自底向上构建语法树，清晰展示程序逻辑结构。
- **语义分析与符号表**：建立符号表作为“唯一权威数据源”，负责变量声明检查与类型匹配。
- **中间表示 (IR)**：生成**四元式 (Quaternary)** 序列，实现前后端逻辑解耦。
- **后端代码生成**：将四元式直接映射为 **x86 汇编 (NASM 格式)**，支持 Linux 64 位环境运行。

**技术关键点：**
1. **符号表枢纽**：符号表记录了所有变量的作用域、类型及内存偏移量，是语法分析与代码生成阶段的数据核心。
2. **自动化链路**：后端生成纯正的 x86_64 汇编，通过 `nasm` 汇编后，利用 `ld` 直接进行系统调用级链接，不依赖标准 C 库 (CRT)，体现了对操作系统底层接口的直接操作。

## 💻Hang 语言编译器

Hang 是一门自定义的类 C 教学语言，旨在通过简洁的语法帮助理解编译原理。本编译器基于 Flex + Bison 实现，将 Hang 源代码编译为 x86-64 汇编，并最终链接为 Linux 可执行文件。

### 语言规范

#### 1. 程序结构
- **入口**：每个 Hang 程序必须以 `hang` 关键字开头，**独占一行**，后面不能跟任何字符（包括空格）。
- **代码块**：`hang` 之后，下一行写左花括号 `{`，程序体结束用右花括号 `}`。
- **语句**：每条语句以分号 `;` 结尾。

```hang
hang
{
    // 你的代码
}
```

#### 2. 注释
当前版本**不支持**注释。请勿在代码中使用 `//` 或 `/* */`。

#### 3. 数据类型
- `int`：整数类型
- `float`：浮点类型（注意：浮点数运算后端支持不完整，建议使用整数）
- `bool`：布尔类型，字面量 `true` / `false`

### 4. 变量声明与赋值
- 可以一行声明多个变量：`int a, b, c;`
- 声明时可同时初始化：`int a = 5;`
- 支持后续赋值：`a = 10;`

#### 5. 运算符
- 算术：`+` `-` `*` `/` (整数除法)
- 比较：`<` `>` `<=` `>=` `==` `!=`
- 赋值：`=`
- 优先级：`*` `/` 高于 `+` `-`；括号 `( )` 可改变优先级

#### 6. 输入输出
- `in(变量)`：从标准输入读入一个整数或浮点数（注意：输入浮点数时后端支持不完整）。
- `out(变量或常量)`：输出到标准输出。

#### 7. 条件控制
- 支持 `when` 条件语句，语法为：
  ```hang
  when(条件表达式)
  {
    语句块
  }
  ```
- **重要**：`when` 的右括号 `)` 和左花括号 `{` **必须分两行写**，即 `)` 换行后再写 `{`。

#### 8. 常量
- 整数：`0` `123` 等
- 浮点数：`3.14`（但后端可能出错，建议避免）
- 布尔：`true` / `false`
- **不支持负数常量**（如 `-5`）。如需负数，请用 `0 - 5` 代替。



## 🛠️ 运行环境与使用方法

### 环境要求
- **Flex / Bison**: 词法与语法分析工具
- **GCC**: 用于编译编译器主体
- **NASM / LD**: 用于后端汇编与链接 (Linux x86_64)

### 快速开始
本项目已集成自动化脚本 `build.sh`。只需传入源文件，脚本将自动完成：**清理 -> 构建编译器 -> 翻译源码 -> 汇编 -> 链接**。

```bash
# 1. 赋予执行权限
chmod +x build.sh

# 2. 运行自动化构建 (以 test.hang 为例)
./build.sh test.hang

# 3. 运行最终生成的二进制程序
./test
